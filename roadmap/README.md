# Дорожня карта TehMeshPlane

| Етап | Результат | Критерій приймання |
| --- | --- | --- |
| 0. Базова панель | Штатний MikroDash, локальний порт, окремий том | Майстер першого запуску відкривається без маршрутизатора. Після повторного запуску можна увійти створеним обліковим записом. |
| 1. Інвентар | Вузли, префікси, фонові спостереження | Зміна стану тестового каналу відображається після повторного відкриття браузера з часом спостереження. |
| 2. Mesh LAN | План тунелів WireGuard, маршрути OSPF, карта та відкат | Повторне застосування дає порожню різницю. При розриві каналу дозволений потік переходить на резервний шлях. |
| 3. Клієнтський доступ | Ключ пристрою, профіль сервісів та відкликання | Дозволений сервіс доступний після перемикання маршруту. Відкликання припиняє активний сеанс. |
| 4. Відновлення | Резервна копія, журнал та звірка | Після відновлення контролер показує відхилення перед записом на вузли. |

Етапи 1–4 заплановано після перевірки базової панелі. Детальні сценарії містить [технічне завдання](TECHNICAL_SPEC.md).
